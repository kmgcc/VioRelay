# 常见问题排查

这份指南会随着更多用户的使用而逐步充实。

如果你遇到了不对劲的情况，欢迎[报告问题](https://github.com/kmgcc/VioRelay/issues/new?template=bug_report.yml)。告诉我们发生了什么、你原本预期的是什么。简单描述几句就够了；如果有截图、日志或版本信息，也请一并附上。

---

# Troubleshooting (English)

This guide will grow as VioRelay reaches more users.

If something is not working as expected, please [report a problem](https://github.com/kmgcc/VioRelay/issues/new?template=bug_report.yml). Tell us what happened and what you expected. A short description is enough to get started; screenshots, logs, and version details are welcome if you have them.
